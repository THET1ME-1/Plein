# Plein

Лаунчер для Android, который берёт цвет с натуры.

Фон приезжает из бесплатного фотобанка, палитра интерфейса считается из самого
кадра, а тёмная тема просит тёмные снимки. Название от пленэра: художник пишет
на природе и берёт цвет с того, что перед ним.

## Как устроен домашний экран

Кадр сверху, приложения на листе, страницы листаются свайпом. Поиск закреплён
внизу и не уезжает вместе со страницами: он ищет по всему телефону, а не по
текущей подборке.

## Что уже есть

- Список приложений через `LauncherApps`, включая рабочий профиль
- Форма значков считается формулой (`RoundedPolygon`), а не берётся у прошивки
- Палитра из кадра и полная схема Material You от одного цвета
- Типографика Unbounded и Onest, тональные поверхности, ноль теней

## Сборка

```
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

Нужны JDK 17 и Android SDK 37.
