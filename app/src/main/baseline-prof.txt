# Baseline profile лаунчера.
#
# Список кода, который Android переводит в машинный заранее, при установке.
# Без него первый запуск и первая прокрутка идут через перевод на лету — это и
# есть те самые «первые кадры дёргаются».
#
# Здесь перечислено то, что исполняется на пути «нажали Домой — увидели сетку»:
# чтение настроек, список приложений, отрисовка значков, кадр и его палитра.
# Библиотеки Compose приносят свои профили сами, дублировать их незачем.
